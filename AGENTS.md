# Repository agent guidance

Read the authoritative [coding standards](CODING_STANDARDS.md) and [domain context](CONTEXT.md) before changes. Follow the repository-local [do-work](.agents/skills/do-work/SKILL.md) and [tdd](.agents/skills/tdd/SKILL.md) workflows; use [code-review](.agents/skills/code-review/SKILL.md) for review.
