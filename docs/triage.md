# Issue triage

This repository uses GitHub Issues. Use these canonical labels to describe the next action:

| Label | Meaning |
| --- | --- |
| `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | Waiting on information from the reporter. |
| `ready-for-agent` | Fully specified and ready for autonomous implementation. |
| `ready-for-human` | Requires human implementation, judgement, or authorized action. |
| `wontfix` | Will not be actioned. |

Create a missing canonical label when triaging an issue that needs it. Type labels such as `bug` or `documentation` can accompany these labels.
